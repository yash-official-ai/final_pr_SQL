# 🎓 University Course Management System

A complete **MySQL Database Management Project** designed to manage university departments, students, courses, instructors, and enrollments using SQL.

## 👨‍💻 Author

**Yash**

## 🛠️ Technologies Used

* MySQL
* SQL
* Relational Database Management

## 📌 Project Overview

This project demonstrates how SQL can be used to manage and analyze university data efficiently. It covers database operations, relationships between tables, data analysis, and advanced SQL queries.

## 🚀 Key Features

* ➕ Create, Read, Update & Delete (**CRUD**)
* 🎓 Student & Course Management
* 🏢 Department Management
* 👨‍🏫 Instructor Management
* 📝 Course Enrollment Tracking
* 🔗 INNER JOIN & LEFT JOIN
* 📊 GROUP BY, HAVING & Aggregate Functions
* 🔍 Subqueries
* 📅 Date & Year Functions
* 🧠 CASE Statements
* 🪟 Window Functions & Running Totals

## 📚 Tasks Covered

The project contains **16 SQL tasks**, including:

* Student enrollment filtering
* Department-wise & course-wise analysis
* Students enrolled in multiple courses
* Average course credits
* Maximum instructor salary
* Student & course joins
* Running enrollment totals
* Senior/Junior student classification

## 🎯 Objective

To build a practical understanding of **SQL database management, relationships, data analysis, and advanced SQL queries** through a real-world university management system.
